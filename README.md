**Boucing window and mouse input registration**

##Bouncing window

The window bounces on the screen and changes the color of it based on its position.
I am not sure if it hits the corner some time but you can check your self.

##Mouse input registration

There is a small black window that you can click in and it will move to another random position.
Also theres a white window in the right-upper corner of the screen and it counts the click.
Warning! It breaks after the number 9 and starts showing letters.
I should fix this but it was a basic test to learn window handling in the Win32 API and to learn more C.
